Embed cross-origin testpagina

Dit is een vreemde origin (serveer deze map op een andere poort dan de runtime) om de embed cross-origin te bewijzen. Serveer bijv. met: 

npx serve scripts/embed-test -l 4173

Zet daarna op de Distributie-tab van de agent (/admin/funds/<fonds>/agents/<agent>/distribution) de CORS-/frame-allowlist op http://localhost:4173 en plak de gegenereerde snippet hieronder in (vervang de data-key). De vanilla loader (~3 KB) verschijnt rechtsonder; React laadt pas in een iframe na klik.
